# 文游工坊 · 云酒馆 Git 安装版 v1.4.0

把 PDF、DOCX、TXT 等资料变成手机端互动文游。适用于带有「安装扩展 → 输入 Git URL」入口的 SillyTavern。

## 安装与更新

本仓库可直接通过 Git URL 安装：

`https://github.com/NEFLIBATE/wenyou-liwu`

已安装用户：在酒馆的扩展管理里更新「文游工坊」，然后完整刷新酒馆页面。仅关闭再打开工坊不会重新加载扩展代码。

手机手动上传文件时，请保留仓库根目录的 `manifest.json`、`index.js`、`host.css`、`app.html`、`app-content.js`、`README.md`。不要只上传 ZIP，也不要再套一层目录。

### v1.4.0 生成稳定性与工坊设置

- 聊天补全在酒馆提供原生请求服务时优先使用流式回复，沿用当前连接与采样设置，生成时显示接收进度；旧版或分支酒馆继续使用原生 generateRaw。通常回复上限由 4,000 降至 2,600 token，开场内容和资料上下文精简；酒馆原生转换为 max_completion_tokens 的模型保留至少 4,096 token 预算，避免思考占满后无正文，并保持原生参数格式。
- 524/504 超时与 503/502 服务不可用会显示明确原因。失败保留表单与游戏进度，提供手动重试、进一步精简及兼容模式重试；不自动发起重复模型请求，也不把失败的 AI 请求伪装成本地成功。兼容模式随存档保存，可在「存档与设置」切回自动。
- 流式请求支持停止和超时中止；不提交部分回复。旧版原生请求若仍在后台运行，会继续阻止并发重试。模型服务本身持续不可用时，仍需恢复服务或更换酒馆连接。
- 上传区按大幅浅绿色虚线卡片重做，带纸张加号图标，支持点击、键盘和实际拖放文件；原有格式、大小限制和解析功能保留。
- 故事题材扩充至 52 种，新增自定义题材（60 字符）。叙事风格可从 16 个选项中选择，也可自定义，均进入每次 AI 提示词并随存档保留。

### v1.3.0 成长、同行、装备与远征

- 成长天赋：初始 1 点，每 4 次非休整行动获得 1 点；寻迹、共情、营生与专注各 3 级，实际改变检定、谋生收入或研习成长。
- 伙伴同行：人物关系达到 8 后可邀请一位伙伴；关系影响检定协助，成功行动会增进关系。关系降至负数时伙伴离队；可随时换人或独自行动。
- 制作与装备：初始 2 份材料，探索与谋生检定成功时收集，远征也会奖励材料。四种配方可消耗材料和资源制作，每次只能装备一件；制作、换装不推进回合。
- 三阶段远征：选择已解锁地点，以稳妥、交涉或冒险路线逐段推进，成功率、体力与评分各不相同。高难地点奖励更高；中途可以休整，进度随存档保留，最终奖励只能领取一次。
- 手册增加成长与远征；剧情页显示整备及继续远征入口。天赋、装备、同行伙伴及远征结算均进入 AI 上下文，本地模式也能完整使用规则。AI 生成失败不消耗回合、材料或阶段进度。
- 旧版存档自动补全新玩法，兼容已有酒馆人设、预设、JSON 和离线 HTML 导出。工坊仍使用四项通用属性，数值上限不变。

### v1.2.0 酒馆人设与预设

- 「02 / 设定」可选择当前或已保存的酒馆用户人设，自动填入主角姓名，完整描述以只读快照用于每次剧情生成。手动人设仍可填写 2,000 字符；酒馆人设最多 20,000 字符，超出时明确提示。
- 可以跟随酒馆当前预设，或指定当前 API 的命名预设。指定预设会在生成时通过酒馆原生接口切换当前预设，采样及连接绑定遵循酒馆行为；切换后保持所选预设，不自动切回旧预设覆盖未保存的修改。
- 聊天补全预设读取启用的提示词、角色、排序及深度插入；游戏状态替代聊天历史，工坊继续要求 JSON 输出。人物卡、其他聊天、世界书与扩展额外的提示词触发规则不自动导入。文本补全沿用酒馆的采样及 instruct 格式。
- 「存档与设置」也可为进行中的旅程更换人设与预设，保存后下一次 AI 生成生效。人设快照及预设名称/API 随 JSON、自动存档和离线 HTML 保留；预设本体、连接配置及密钥不写入存档。
- 刷新列表可读取酒馆刚新增的内容。人设删除后已有快照仍可使用；预设删除或 API 类型变化会明确提示重新选择。离线只能使用保存的人设与本地规则，不能调用酒馆预设。

### v1.1.0 可玩性更新

## 手机上传 GitHub

1. 打开 https://github.com/new ，登录你自己的 GitHub 账号。
2. 创建一个新的空仓库，例如 `wenyou-forge`。选择 Public（公开），以便云酒馆无需仓库凭据即可读取；包里是扩展代码，不要往仓库加入自己的资料或密钥。
3. 在空仓库首页点击「uploading an existing file」。如果仓库已有文件，选择「Add file → Upload files」。
4. 点击「choose your files」，在手机文件选择器内选中上文列出的文件，然后完成提交。
5. 回到仓库首页，确认文件列表直接显示 `manifest.json`、`index.js`、`app.html` 和 `app-content.js`。
6. 复制仓库首页地址（格式见下文），回云酒馆的安装扩展弹窗粘贴并安装。分支栏可留空，使用默认分支。

仓库地址格式示意，必须替换成你实际建立的仓库：

`https://github.com/你的GitHub用户名/wenyou-forge`

这不是现成的可安装链接。不要直接复制带「你的GitHub用户名」的示例。

手机网页看不到上述按钮时，可尝试浏览器的「桌面版网站」；不同GitHub页面布局可能略有区别。

## 云酒馆内安装

1. 点击顶部积木图标进入扩展页。
2. 点击「安装扩展程序」。
3. 在「输入扩展程序的 Git URL 以安装」弹窗中，粘贴真实仓库地址。
4. 分支 / 标签留空。若要指定分支，填写你仓库里实际存在的分支名。
5. 点击安装，成功后刷新酒馆；在扩展设置里找到「文游工坊」并点击「打开文游工坊」。
6. 上传游戏资料，选择AI模式，生成并游玩。

不要填进「下载扩展程序和资源 → 资源网址」输入框：那里接收资源列表，不是这个扩展的Git仓库地址。

## 功能和使用条件

- 上传PDF、DOCX、TXT、MD、JSON、CSV；一次最多6个，每个≤16MB，总提取文字≤50万字符，PDF≤200页。
- 清新卡片页面，剧情选择、回合推进、随机事件、玩家数值、NPC互动及关系累计。
- AI模式使用酒馆当前模型，不需在扩展内重复填写密钥。若酒馆显示「未连接到API」，先连接模型；否则可先用本地规则体验。
- 本地提取文件文字；选择AI生成后，会把相关资料片段与游戏状态发送到当前连接的模型。
- PDF仅提取文字层；扫描件需先OCR。DOCX读取文字，旧DOC请先转DOCX。复杂表格、图片和原页面排版不保留。
- 本地规则体验使用资料摘录和通用事件；它不等同于AI原创剧情。
- 四项通用属性为体力、心情、洞察、资源；任务、背包、检定和日程使用工坊内置规则，不自动编译任意资料中的复杂数值系统。
- 自动存档存在当前浏览器，同一酒馆地址共用一个当前进度，不与聊天或账户自动隔离；重要进度请导出JSON。
- 支持导出带存档的完整单文件HTML；离开酒馆后使用本地规则继续。

## 无法安装时

有安装入口不保证云端开放了相应权限，或能够访问GitHub。如果提示安装被禁用、权限不足或网络错误，请向云酒馆管理员确认第三方扩展安装和GitHub访问是否开放。不能通过角色卡导入绕过这些限制。

本扩展按近期官方SillyTavern的 `SillyTavern.getContext().generateRaw({...})` 接口开发，不依赖Extras或酒馆助手。云酒馆若使用旧版或修改版，仍需实际验证兼容性。

v1.0.1 增加针对窄屏、横屏、主题覆盖、背景点击、关闭重开、页面加载失败与重试的浏览器回归检查。实际云酒馆登录状态、实际模型及安卓实体设备仍需安装更新后验证。
